\begin{abstract}
Sleep-disorder screening from inexpensive lifestyle and health measurements is an important decision-support problem, but high reported accuracy can be misleading when data leakage, class imbalance, and weak validation are not controlled. This study presents a reproducible, explainable stacking pipeline for three-class screening of None, Insomnia, and Sleep Apnea. The pipeline performs deterministic variable auditing, blood-pressure decomposition, target harmonisation, train-only transformation fitting, and stratified evaluation. A tuned Random Forest and XGBoost pair is combined by a logistic-regression meta-learner, while permutation-based SHAP values provide a model-agnostic audit of feature influence. On the repository's 374-record dataset, the recorded 80:20 stratified hold-out experiment (75 test observations) achieved 97.33\% accuracy, macro-precision 0.96, macro-recall 0.96, and macro-F1 0.96. The strongest class-wise F1 scores were 0.93 for Insomnia, 1.00 for None, and 0.94 for Sleep Apnea. These findings support the ensemble as a strong research baseline, not as a clinical diagnosis. The manuscript supplies an explicit evaluation protocol, ten methodological figures, implementation algorithms, and a responsible-use boundary for future external validation.
\end{abstract}

\section{Introduction}
Sleep disorders affect daytime functioning, mental health, cardiometabolic risk, and quality of life. Obstructive sleep apnea is particularly important because symptoms may be under-recognised while untreated disease can carry substantial health consequences \cite{senaratna2017,patel2019,kapur2017}. Polysomnography remains a definitive diagnostic test, but its cost, infrastructure requirements, and limited availability motivate risk stratification tools that can identify individuals who merit formal assessment \cite{collop2007,berry2017}.

Tabular lifestyle data create a useful but difficult machine-learning setting. Predictors are heterogeneous, categorical fields may contain inconsistent labels, and the target distribution is often unequal. More importantly, a random train--test result can be inflated when preprocessing is fitted before splitting or when repeated experimentation is not acknowledged \cite{kuhn2019,kapoor2021}. A credible study therefore needs an auditable pipeline, class-sensitive reporting, uncertainty-aware interpretation, and a clear statement that screening is not diagnosis.

This article makes four contributions. First, it defines a complete preprocessing protocol for the Sleep Health and Lifestyle Dataset. Second, it documents a tuned stacking ensemble in which bagged and boosted trees contribute complementary probability estimates \cite{breiman2001,chen2016,wolpert1992}. Third, it adds a model-agnostic explanation layer using SHAP values and discusses its limitations \cite{lundberg2017,lundberg2020}. Fourth, it presents ten diagrams and four analytical tables so that another group can reproduce the workflow and evaluate it on an independent cohort.

\section{Clinical and methodological context}
Sleep-disorder prediction should be understood as a triage problem. Screening tools can prioritise a referral or a confirmatory test; they should not replace clinical history, physical examination, polysomnography, or specialist judgement \cite{americanacademy2014,patel2019}. The American Academy of Sleep Medicine classification also makes clear that sleep disorders are clinically heterogeneous, whereas the present dataset contains only three broad labels \cite{americanacademy2014}.

From a machine-learning perspective, Random Forest is a robust non-linear tabular learner based on decorrelated trees \cite{breiman2001}. XGBoost introduces regularised gradient boosting and efficient split finding for structured data \cite{chen2016}. Stacking learns a second-level function over out-of-fold predictions and can exploit the distinct error profiles of its base learners \cite{wolpert1992,van1999}. These models are paired with scikit-learn's compositional pipeline design \cite{pedregosa2011}, while SHAP provides additive attributions that can be aggregated for an exploratory global audit \cite{lundberg2017,lundberg2020}.

\section{Materials and methods}
\subsection{Dataset and label construction}
The source file contains 374 records and 13 columns. The target is \textit{Sleep Disorder}, with the values None, Insomnia, and Sleep Apnea. In the repository implementation, missing target values are mapped to None following the dataset convention. Person ID is an administrative identifier and is excluded. The remaining predictors describe age, gender, occupation, sleep duration, sleep quality, physical activity, stress, BMI category, blood pressure, heart rate, and daily steps. The dataset is publicly distributed through Kaggle \cite{kaggle_sleep}; no claim is made that its labels are equivalent to clinician-adjudicated diagnoses.

\subsection{Data splitting and leakage control}
The data are divided into training and test partitions using an 80:20 stratified split with random seed 42. The recorded experiment contains 299 training and 75 test observations. Numerical standardisation and one-hot encoding are fitted on the training partition and then applied unchanged to the test partition. This ordering is essential because test-set statistics must not influence the learned representation \cite{kuhn2019,kapoor2021}.

\begin{algorithm}[t]
\caption{Leakage-safe data preparation}
\label{alg:prep}
\begin{algorithmic}[1]
\Require Dataset $D$, target $y$, seed $s=42$
\Ensure Transformed partitions $(X'_{tr},y_{tr})$ and $(X'_{te},y_{te})$
\State Remove identifier fields and map missing target values to None
\State Harmonise BMI labels and split Blood Pressure into two integers
\State Perform an 80:20 stratified split using seed $s$
\State Fit the scaler and one-hot encoder on $X_{tr}$ only
\State Transform $X_{tr}$ and $X_{te}$ using the fitted objects
\State Fit the label map on $y_{tr}$ and apply it to $y_{te}$
\State \Return $(X'_{tr},y_{tr})$, $(X'_{te},y_{te})$
\end{algorithmic}
\end{algorithm}

\subsection{Base learners and stacking design}
The first base learner is a Random Forest with 100 trees, maximum depth 10, minimum split size 5, minimum leaf size 2, and seed 42. The second is XGBoost with 800 estimators, learning rate 0.02, maximum depth 3, subsample 0.90, column subsample 0.90, minimum child weight 3, $\gamma=0.15$, and $\lambda=1.2$. A logistic-regression meta-learner receives the probability vectors generated by the two base learners. During training, the meta-learner must receive out-of-fold predictions rather than predictions from models fitted on the same rows; otherwise the stack can overfit its second level \cite{wolpert1992,van1999}.

\begin{algorithm}[t]
\caption{Out-of-fold stacking prediction}
\label{alg:stack}
\begin{algorithmic}[1]
\Require $(X'_{tr},y_{tr})$, test vector $x$, $K=5$ folds
\Ensure Predicted class $\hat y$
\For{$k=1$ to $K$}
\State Fit $f_{RF}^{(-k)}$ and $f_{XGB}^{(-k)}$ outside fold $k$
\State Store probabilities on fold $k$ as $P_{RF}^{(k)}$ and $P_{XGB}^{(k)}$
\EndFor
\State Concatenate out-of-fold probabilities $P=[P_{RF},P_{XGB}]$
\State Fit logistic meta-learner $g$ on $(P,y_{tr})$
\State Fit both base learners on all $X'_{tr}$
\State $\hat y\gets\arg\max_c g([f_{RF}(x),f_{XGB}(x)])_c$
\State \Return $\hat y$
\end{algorithmic}
\end{algorithm}

\subsection{Explainability and auditability}
SHAP explanations are computed through a permutation-based, model-agnostic interface. A fixed background subset is drawn from training data; categorical values are encoded for the explainer and decoded before inference. For feature $j$, the global audit score is
\begin{equation}
I_j=\frac{1}{n}\sum_{i=1}^{n}|\phi_{ij}|,
\end{equation}
where $\phi_{ij}$ is the contribution assigned to feature $j$ for observation $i$. This quantity is an association with model output, not a causal effect, and correlated features can share or exchange attribution \cite{lundberg2017,lundberg2020,ar2023}.

\begin{algorithm}[t]
\caption{Permutation-SHAP model audit}
\label{alg:shap}
\begin{algorithmic}[1]
\Require Fitted model $F$, training matrix $X_{tr}$, explanation sample $X_e$
\Ensure Ranked importance vector $I$
\State Sample a fixed background $B\subset X_{tr}$
\State Define $h(z)=F(\operatorname{decode}(z))$
\State Initialise a permutation explainer with $h$ and $B$
\State Compute $\Phi$ for $X_e$
\State $I_j\gets\operatorname{mean}_i(|\Phi_{ij}|)$ for each feature $j$
\State Rank features by decreasing $I_j$
\State \Return $I$
\end{algorithmic}
\end{algorithm}

\section{Experimental protocol}
The primary experiment is the recorded single stratified hold-out evaluation. Accuracy is reported with macro-precision, macro-recall, and macro-F1 because the class counts are unequal. For class $c$, precision and recall are $TP_c/(TP_c+FP_c)$ and $TP_c/(TP_c+FN_c)$, respectively; the class F1 is their harmonic mean. Macro-F1 gives each class equal weight, while weighted-F1 uses class support. No claim of statistical superiority is made from one split. A journal-grade follow-up should use repeated nested cross-validation, bootstrap confidence intervals, calibration curves, subgroup analysis, and an untouched external cohort \cite{vabalas2019,steyerberg2010,van2020}.

\section{Results}
The stacking model correctly classified 73 of 75 test observations, yielding 97.33\% accuracy. The recorded confusion matrix contains 13/15 correct Insomnia predictions, 44/44 correct None predictions, and 16/16 correct Sleep Apnea predictions. The two errors were Insomnia records assigned to Sleep Apnea. The soft-voting comparator achieved 96.00\% accuracy and macro-F1 0.94 in the repository notebook.

\section{Discussion}
The recorded result is strong for a small tabular benchmark, but it should be interpreted cautiously. The model may benefit from structured variables that are close to the dataset's label construction. The perfect None recall and Sleep Apnea recall on this split may not persist under population shift. Insomnia has lower recall, indicating a clinically meaningful failure mode if the tool were used as a gatekeeper. In practice, the operating threshold should be selected with a clinically justified utility function rather than by accuracy alone \cite{vickers2006,steyerberg2010}.

The ensemble design is defensible because its two base learners make different inductive assumptions. Random Forest averages high-variance trees, whereas boosted trees iteratively reduce residual error. The meta-learner can exploit those differences, but stacking does not automatically guarantee generalisation. It must be trained on out-of-fold predictions, and all feature processing must remain inside the training pipeline \cite{wolpert1992,kuhn2019}.

SHAP improves auditability but does not solve causality, fairness, or calibration. Attribution rankings can be unstable under correlated predictors, and a plausible explanation does not prove that a feature is medically causal \cite{rudin2019,ar2023}. For deployment, explanations should be accompanied by calibration, subgroup error analysis, missing-data analysis, and human-factors testing \cite{chen2023,kaur2022}.

\section{Limitations}
The study has six limitations. The dataset is small and publicly sourced; its sampling process and label quality are not fully documented. The primary result comes from one hold-out split and therefore has no confidence interval. No independent hospital cohort or prospective evaluation is available. The labels do not include polysomnography-derived severity. The SHAP audit is exploratory and based on a limited background/sample design. Finally, the repository contains multiple experimental notebooks, so future work should consolidate the pipeline into a single version-controlled training script with a pre-registered evaluation protocol.

\section{Conclusion}
This study provides a substantially documented, explainable stacking baseline for multi-class sleep-disorder screening. The recorded Random Forest--XGBoost stack achieved 97.33\% accuracy and 0.96 macro-F1 on the available stratified hold-out set. Ten figures and four tables make the methodological path explicit, while the limitations prevent overinterpretation. The next scientific step is not to claim clinical readiness, but to test calibration, subgroup robustness, uncertainty, and external prospective validity against clinician-adjudicated outcomes.
